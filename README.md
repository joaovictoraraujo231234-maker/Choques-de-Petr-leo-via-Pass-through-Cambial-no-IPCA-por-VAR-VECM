# Choques-de-Petr-leo-via-Pass-through-Cambial-no-IPCA-por-VAR-VECM
Análise econométrica (VAR/VECM) dos impactos dos choques do petróleo (Brent) e do repasse cambial (Pass-through) na inflação brasileira (IPCA). Desenvolvido em Python, contempla extração de dados (APIs), testes de estacionariedade, cointegração e isolamento da política de paridade (PPI) via variável dummy.
